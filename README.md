# 🚀 Idea2Run

**让想法跑起来。**

说出你的想法，找到可用的开源项目，选一个方案，再让 Agent 按计划一步步推进。

**简体中文（默认）** | [English](README.en.md) · [快速上手](#快速上手) · [能帮你什么](#能帮你什么) · [开发文档](docs/development.zh-CN.md)

## 从一个想法开始

“我想做一个本地照片整理工具。”

“我想搭建一个团队知识库。”

“我想根据 Word 文件的内容自动命名。”

Idea2Run 会先弄清关键需求，搜索能用的开源项目，给你几个看得懂的方案。你选定后，它再展开完整计划；确认计划后，可以自己实施，也可以让 Agent 执行，或复制简短提示词交给其他 Agent。

```text
说想法 → 看方案 → 选方案 → 看计划 → 确认 → 分步推进
```

## 快速上手

首版支持 **Codex**，需要宿主版本支持插件。把这句话发给你的 Agent：

```text
帮我在 Codex 中安装 Idea2Run：https://github.com/wangyangwjy/idea2run 。请按 README 的安装说明操作，完成后告诉我如何开始使用。
```

<details>
<summary>自己安装：两条命令</summary>

```powershell
codex plugin marketplace add wangyangwjy/idea2run
codex plugin add idea2run@idea2run
```

如果当前版本不支持插件命令，可以使用[项目内技能安装方式](docs/development.zh-CN.md#本地开发安装)。

</details>

安装后**新开任务**，输入 `$` 选择 Idea2Run，再说你的想法：

```text
$idea2run 我想做一个本地照片整理工具
```

只需在开始时选一次。后续直接回复“选第二个”“可以”“继续”，无需反复输入长指令。如果插件尚未显示，重启应用后再选择。

## 能帮你什么

| 你要做的事 | Idea2Run 给你的结果 |
| --- | --- |
| 找到可用的开源项目 | 项目链接、适合的用途、环境要求和主要限制 |
| 决定怎么实现 | 通常 2—3 个有实质区别的方案，优先能直接使用或少量修改的路线 |
| 知道接下来做什么 | 选定方案的完整计划，包含阶段产物、验证方法和失败处理 |
| 交给 Agent 推进 | 一次一个阶段的简短提示词，可交给当前或其他 Agent |
| 处理执行中的问题 | 根据实际反馈继续；失败时先修复当前阶段 |

你决定选哪个方案、是否批准计划，以及是否交给 Agent 执行。方案发生变化时，需要重新核对确认。

## 保持轻量

- **用已有的 Agent。** 模型、搜索和执行工具由宿主提供，无需为 Idea2Run 额外注册账号或接入独立模型接口。
- **先找现成项目。** 推荐附真实来源，优先部署、配置或少量改造。
- **每次推进一步。** 每条交接提示词最多 2400 个字符，围绕一个可验证的产物。
- **进度按需保存。** 可选的本地工具只记录进度、导出计划和提示词，不执行计划中的命令。

## 常见问题

**直接说想法，会自动调用吗？**

宿主可以根据请求自动选用技能，但不保证每次都触发。需要明确调用时，输入 `$idea2run`，或输入 `$` 选择 Idea2Run。

**支持哪些 Agent？**

首版插件接入 Codex。生成的提示词可以复制给其他 Agent；其他宿主的插件兼容性仍待验证。参见[官方技能与插件调用说明](https://learn.chatgpt.com/docs/skills-and-plugins)。

**需要付费或安装本地模型吗？**

插件不接入额外的付费模型接口，也不要求安装本地模型。宿主本身的使用费用，以及所选方案的下载量、硬件和服务成本，仍取决于具体环境与方案。

**没有联网搜索怎么办？**

会说明限制，使用你提供的资料，或将候选保留为待核对。文档核对与实际运行验证分别记录。

## 当前进展

**v0.1.1 · 早期版本**，已提供方案比较、计划生成、分步交接、本地进度与导出工具。仓库的 **9 项自动化测试**覆盖进度和交接工具。

已有一次 Windows Word 文件按内容命名的真实使用记录：用户确认方案并授权当前 Agent 实现，完成工具实现和样本副本验证。目标目录自动处理尚未开启；跨 Agent 复制提示词的完整流程仍待验证。上面的想法示例不代表所有场景已实测。私人会话和用户文件不放进仓库。

后续优先改进：更早弄清关键需求、选型时讲清实施负担、交付时明确如何启动和使用。欢迎把实际使用中的问题提交到 [Issues](https://github.com/wangyangwjy/idea2run/issues)。
